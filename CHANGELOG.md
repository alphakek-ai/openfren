## [0.1.0] - 2025-11-02
### Added
- Initial open-source release.
- `src/` package layout with `openfren` library.
- CLI entrypoint `openfren` with `--question` override.
- CI for Python 3.13/3.14 on Linux/macOS/Windows.
- Pre-commit hooks: Ruff (format+lint), ty, pytest on push.
- Release workflow using `uv build` and `uv publish` (Trusted Publishing).
- README/DEVELOPMENT docs, `env.example`.
